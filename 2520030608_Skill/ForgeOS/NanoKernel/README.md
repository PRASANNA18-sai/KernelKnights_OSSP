# NanoKernel

## Overview

NanoKernel is the kernel-space component of the ForgeOS project developed as part of the Operating Systems and System Programming (OSSP) course.

## Objectives

- Understand kernel-space programming
- Explore Linux kernel architecture
- Implement kernel-level functionalities as instructed during the course
- Learn memory management, process management, and kernel modules
- Gain practical exposure to operating system internals

## Technologies

- C Programming
- Linux Kernel
- Kernel Modules
