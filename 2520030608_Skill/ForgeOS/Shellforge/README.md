# Shellforge

## Overview

Shellforge is a Unix-style command-line shell developed from scratch in the C programming language as part of the Operating Systems and System Programming (OSSP) course.

## Objectives

- Understand how a Linux shell works
- Execute user commands using system calls
- Manage processes and process creation
- Implement command parsing and execution
- Support input/output redirection and pipes
- Gain hands-on experience with system programming concepts

## Technologies

- C Programming
- Linux
- POSIX System Calls
