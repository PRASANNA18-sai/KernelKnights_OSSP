# NanoKernel

## Overview

NanoKernel is the kernel-space component of the ForgeOS project developed as part of the **Operating Systems and System Programming (OSSP)** course.

This project focuses on understanding Linux kernel internals and implementing kernel-level functionalities as instructed during the course.

## Objectives

- Understand kernel-space programming
- Learn Linux kernel architecture
- Explore process and memory management
- Study kernel modules and system-level programming
- Gain practical experience with operating system internals

## Technologies Used

- C Programming
- Linux
- Linux Kernel
- Kernel Modules

## Status

🚧 **Under Development**

The NanoKernel project will be developed incrementally throughout the semester based on the course requirements.
