# NanoKernel

## Overview

NanoKernel is the kernel-space component of the ForgeOS project.

This project focuses on understanding Linux kernel architecture and implementing kernel-level functionalities as part of the OSSP course.

## Objectives

- Learn kernel-space programming
- Understand Linux kernel architecture
- Explore memory and process management
- Study kernel modules and system-level programming
- Gain practical experience with operating system internals

## Technologies

- C Programming
- Linux Kernel
- Kernel Modules

🚧 Under Development

Kernel-space components will be implemented progressively according to the course requirements.
