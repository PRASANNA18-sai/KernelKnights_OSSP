# ForgeOS

## Overview

ForgeOS is the semester project developed as part of the **Operating Systems and System Programming (OSSP)** course.

The project consists of two independent components:

- **Shellforge** – A Unix-style command-line shell developed from scratch in C (User Space).
- **NanoKernel** – Kernel-space components developed according to the course requirements (Kernel Space).

## Objectives

- Understand operating system architecture
- Learn Linux system programming
- Explore process and memory management
- Study file systems and inter-process communication
- Gain practical experience with user-space and kernel-space development
