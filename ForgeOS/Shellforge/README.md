# Shellforge

## Overview

Shellforge is a Unix-style command-line shell implemented from scratch in the C programming language.

It is the user-space component of the ForgeOS project and is designed to provide hands-on experience with Linux system programming concepts.

## Objectives

- Understand how a shell works
- Execute Linux commands
- Create and manage processes
- Use POSIX system calls
- Implement pipes and I/O redirection
- Explore process synchronization

## Technologies

- C Programming
- Linux
- POSIX System Calls
